# Vowora — Interlace Union Emblem

Concept-stage SVG assets for Vowora. The two overlapping ellipses symbolize partnership and union.

- `vowora-wordmark-light.svg`: horizontal logo for light backgrounds
- `vowora-wordmark-dark.svg`: horizontal logo for dark backgrounds
- `vowora-app-icon-forest.svg`, `-ivory.svg`, `-sage.svg`: square app-icon options
- `vowora-favicon-forest.svg`, `-ivory.svg`, `-transparent.svg`: favicon options

Colors follow the approved UI design system: forest #293C35, ivory #F8F8F5, sage #789587, light sage #A9C5B0, and dark-mode foreground #F1F5EF. Wordmarks use editable DM Sans text; outline the text for self-contained production assets. The transparent favicon is intended for light backgrounds. These are review assets, not finalized accessibility- or trademark-cleared artwork.

Source of truth: [UI Design System](../../product/UI-DESIGN-SYSTEM.md).
