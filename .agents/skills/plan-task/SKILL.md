# Plan one task

1. Read `AGENTS.md`, the canonical product specification, the existing architecture document, and `docs/PLANS.md`.
2. Select one bounded vertical slice; cite its exact product sections and decision IDs.
3. Identify assumptions, dependencies, missing decisions, security/privacy implications, and relevant permissions.
4. Propose in-scope and out-of-scope work, likely affected areas, acceptance criteria, and test cases.
5. Suggest whether the task can be delegated safely; avoid overlapping write ownership.
6. Stop for approval. Do not edit application code, architecture, product requirements, or design-system files.
