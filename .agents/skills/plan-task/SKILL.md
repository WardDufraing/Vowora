# Plan one task
1. Read `AGENTS.md`, `docs/PLAN.md`, the selected `docs/steps/NN-x.md`, dependent merged handoffs, and only relevant cited portions of frozen `docs/product/*` sources.
2. Confirm prerequisites, status, task ownership and any open PR. Do not use superseded `docs/PLANS.md`.
3. Trace exact product and architecture IDs; define scope, non-goals, interfaces, security/privacy constraints, acceptance criteria, tests, risks and owner actions.
4. Flag contradictions and missing decisions without inventing requirements. Split oversized tasks only through an approved roadmap change.
5. Hand off to a fresh implementation agent. Planning alone does not authorize merging, deployment, destructive actions or changes to frozen documents.
